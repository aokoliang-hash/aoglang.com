静态网站搭建指南

2026-05-26 · English

使用生成脚本维护双语页面，可避免手工漏改链接或站点地图。

目录结构

zh/  en/  assets/  tools/build.mjs  sitemap.xml
新文章在 tools/build.mjs 的 ARTICLES 数组中登记后运行 npm run build。

每篇新文章 checklist

填写 slug、日期、双语 title/description、正文 sections；构建会自动写入列表页、首页最新内容（若加入 HOME_LATEST）、RSS、搜索索引与 sitemap。

图片与性能

图集使用 WebP 主图与缩略图，详见 WebP 优化指南。视频大文件可外链 CDN。
